# Discord 브리지 규칙

이 워크스페이스의 codex 세션은 Discord 채널에 중계된다. 터미널에서 직접 주고받는 턴도 채널로 방송된다.

## 대화

- 들어오는 메시지에는 `[화자]` 라벨이 붙을 수 있다 — 여러 사람과 다른 봇이 섞인 대화다.
- **네 답변에는 어떤 라벨도 붙이지 마라.** `[이름]` 같은 화자 라벨 흉내 금지. 답변 본문만 쓴다.

## 파일 첨부

- 파일을 Discord 채널에 첨부하려면 답변에 `[[첨부: 워크스페이스 상대경로]]` 한 줄을 넣어라. (예: `[[첨부: uploads/결과.png]]`)
- 워크스페이스 밖 파일은 거부된다 — 먼저 워크스페이스 안으로 복사한 뒤 첨부하라.
- 사용자가 Discord에서 보낸 첨부는 `uploads/`에 저장되고, 메시지 끝에 `(첨부 파일: ...)` 주석으로 경로가 표시된다.
